# PROJECT

Build a web application called:

Hive Inspect Template Importer

The application imports inspection-template spreadsheets exported from Spectora, converts them into a structured editable template model, stores the result in Supabase/PostgreSQL, and allows the user to view, edit, and independently duplicate templates.

The primary target for this assignment is WEB.

Use React Native Web so the architecture can later support Android/iOS with maximum code reuse.
